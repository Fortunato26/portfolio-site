# Portfólio Pessoal

Meu portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro. Design moderno, responsivo e otimizado para performance.

## 🚀 Demonstração

[Ver portfólio ao vivo](https://fortunato26.github.io/portfolio-site/)

## 📋 Sobre o Projeto

Este portfólio foi criado para demonstrar minhas habilidades como desenvolvedor front-end. O site é:

- **100% responsivo** — funciona em desktop, tablet e mobile
- **Sem frameworks** — HTML, CSS e JavaScript puros
- **Design moderno** — interface limpa e profissional
- **Otimizado** — carregamento rápido e acessível

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura semântica
- **CSS3** — Flexbox, Grid, Custom Properties, Animações
- **JavaScript** — DOM API, Intersection Observer, Smooth Scroll
- **Google Fonts** — Inter

## 📁 Estrutura do Projeto

```
portfolio-site/
├── index.html      # Página principal
├── styles.css      # Estilos
├── script.js       # Interatividade
└── README.md       # Este arquivo
```

## ⚙️ Como Executar

1. Clone o repositório
```bash
git clone https://github.com/Fortunato26/portfolio-site.git
```

2. Abra o arquivo `index.html` no navegador

Ou acesse diretamente: https://fortunato26.github.io/portfolio-site/

## 🎨 Personalização

Para personalizar o portfólio:

1. Edite `index.html` com suas informações
2. Altere as cores em `styles.css` (variáveis CSS no topo)
3. Adicione ou remova projetos na seção de projetos
4. Atualize os links sociais

## 📱 Responsividade

O site é totalmente responsivo e funciona em:
- Desktop (1100px+)
- Tablet (768px - 1100px)
- Mobile (até 768px)
