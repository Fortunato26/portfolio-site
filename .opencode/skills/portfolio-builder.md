# Skill: Portfolio Builder

## Description
Creates and maintains professional portfolio websites for developers. Generates HTML/CSS/JS code with modern design, responsive layouts, and best practices.

## When to Use
- Creating new portfolio sites
- Updating portfolio content
- Adding new projects
- Improving design and UX

## Instructions

### Design Principles
1. **Dark mode first** — Use black (#0a0a0a) as base
2. **Gold accents** — Use #d4af37 for highlights
3. **Minimalist** — Clean layout, lots of whitespace
4. **Responsive** — Mobile-first approach
5. **Fast** — No heavy frameworks, pure HTML/CSS/JS

### Brand Colors
```css
--black: #0a0a0a;
--gold: #d4af37;
--gold-light: #f4d03f;
--gold-dark: #c9a227;
```

### Structure
```
portfolio-site/
├── index.html      # Main page
├── styles.css      # Styles
├── script.js       # Interactivity
├── assets/         # Images, icons
└── README.md       # Documentation
```

### Sections to Include
1. **Hero** — Name, title, CTA buttons
2. **About** — Brief bio, stats
3. **Skills** — Technical skills grouped
4. **Experience** — Timeline format
5. **Projects** — Card grid with links
6. **Contact** — Email, LinkedIn, GitHub

### Code Quality
- Semantic HTML5
- CSS Custom Properties
- No external dependencies
- Accessible (ARIA labels)
- SEO optimized (meta tags)
