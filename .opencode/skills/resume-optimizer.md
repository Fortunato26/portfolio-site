# Skill: Resume Optimizer

## Description
Optimizes resumes/CVs for tech jobs. Analyzes job descriptions, suggests improvements, and ensures ATS compatibility.

## When to Use
- Creating or updating CV/resume
- Applying for tech jobs
- Preparing for interviews
- Tailoring resume for specific roles

## Instructions

### Resume Structure
1. **Header** — Name, contact, LinkedIn, GitHub
2. **Objective** — 2-3 lines, tailored to job
3. **Experience** — Reverse chronological, action verbs
4. **Skills** — Categorized, honest levels
5. **Education** — Including incomplete if relevant
6. **Projects** — With links and metrics

### ATS Optimization
- Use standard section headers
- Include keywords from job description
- Avoid tables and complex formatting
- Save as PDF with clear filename
- No headers/footers

### Action Verbs
```
Desenvolvi, Implementei, Otimizei, Gerenciei,
Integrei, Configurei, Automatizei, Reduzi,
Aumentei, Colaborei, Lidei, Coordenei
```

### For Front-End Roles
Highlight:
- React, TypeScript, Next.js
- Git/GitHub
- Responsive design
- Performance optimization
- Testing (Jest, RTL)

### For E-commerce Roles
Highlight:
- Shopify, WooCommerce
- ERP integration (Bling)
- Marketplace management
- Inventory optimization
- API integration
